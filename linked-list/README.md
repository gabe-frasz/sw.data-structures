# linked-list

Linked-list implementations for integer values.

## Implementations

- `standard.c` — singly linked list.
- `with-head.c` — singly linked list with a head structure.
- `circular.c` and `circular-with-head.c` — circular singly linked lists.
- `circular-doubly.c` and `circular-doubly-with-head.c` — circular doubly linked lists.
